## 制作方式 / 致谢

本项目通过 Agent Skill **`edu-chem-reaction`** 制作，来自开源仓库：

**[wy51ai/edulab](https://github.com/wy51ai/edulab)**

```bash
npx skills add https://github.com/wy51ai/edulab --skill edu-chem-reaction
```

该 skill 的作用是「把一个化学反应做成一个自包含的微观 3D 交互演示网页」——Three.js 分子动画 + KaTeX 方程 + 分步讲解 + 原子守恒计数，由 sympy 驱动配平与守恒校验，内置 `morph`（原子变形，展示原子守恒）与 `mechanism`（机理关键帧，展示催化/过渡态）两套引擎。

本项目与它的关系：

| 部分 | 来源 |
|---|---|
| 26 个章节页的原始形态 | 由 `edu-chem-reaction` 生成（数据里的 `"engine": "morph"` 即其原子变形引擎） |
| `网页/` 原始 32 个 HTML | 该 skill 的产出，作为数据源保留未改动 |
| 289 个方程的整理与勘误 | 人工整理，见 `方程式/LaTeX 版/勘误说明.md` |
| **合并为单文件、离线化、三级导航、搜索/深链、选择栏收起** | 本项目在 skill 产出之上追加（见下方「构建」与 `tools/`） |

> 注意：`tools/` 下的合并与离线化脚本是本项目自建的，不属于 `edulab` 仓库。

## 功能

- **三级导航**：册 → 章 → 方程。顶部切换分册与章节，卡片栏切换本章方程。
- **3D 演示**：拖拽旋转 / 滚轮缩放 / 右键平移；进度滑块 + 自动播放，展示旧键断裂（橙）→ 原子重组 → 新键生成（绿）。
- **配套面板**：分步讲解、原子图例、**原子守恒计数**、分子标签开关、能量—反应进程曲线（热化学）、电子转移（电化学）。
- **搜索**：`Ctrl/Cmd + K` 或点击搜索框，按方程内容/关键字定位（如「氯气」「电解」）。
- **深链**：地址栏 `#册/章/方程` 可直接定位，便于老师把某个方程发给学生。
- **键盘**：`←` `→` 切换上/下一个方程。

## 构建

需要 Node 18+。

```bash
node tools/fetch-vendor.mjs   # 下载离线依赖到 _vendor/（只需一次，或升级依赖时）
node tools/extract-data.mjs   # 从 网页/*.html 抽取 289 个方程 -> src/data/*.js
node tools/build-player.mjs   # 从 网页/ 抽取播放器 -> src/player.js（+ styles.css / skeleton.html）
node tools/build.mjs          # 产出 dist/ 单文件 与 dist-src/ 源码版
```

改方程的流程：编辑 `src/data/*.js`（或改原始 md 后重跑 `extract-data.mjs`）→ `node tools/build.mjs`。

## ⚠️ 科学性错误提示（重要）

**本项目的 3D 演示是示意性动画，不是精确的分子/晶体结构模拟。部分方程式的 3D 演示存在科学性错误或不严谨之处，使用时请以教材和教师讲解为准，不要直接把动画当作结构依据。**

已知/潜在的问题类型（待逐条核实后填充具体清单）：

| 类别 | 说明 |
|---|---|
| 离子化合物 | 如 NaCl、CuO 等离子晶体本为巨型晶格，动画常画成独立"分子对"，易误导 |
| 键型 | 离子键与共价键用同一种"棍"表示；`order: "ionic"` 仅作视觉区分，非真实键级 |
| 有机结构 | 为简化常画成平面/直线排列，与真实空间构型（如甲烷正四面体、苯环平面）不符 |
| 原子半径/比例 | 半径取自显示美观需要，非真实相对大小 |
| 反应机理 | 动画是"断键—重组"的示意，真实反应多经中间体、过渡态，不如此直接 |
| 电子转移 | 电化学页的电子动画为示意，不代表真实迁移路径与顺序 |
