# 选择性必修3

### 第一章 有机化合物的结构特点与研究方法

1. **甲烷的氯代（取代反应）**  
   CH₄ + Cl₂ =光照= CH₃Cl + HCl
2. **乙烯与溴的加成**  
   CH₂=CH₂ + Br₂ = CH₂Br-CH₂Br

---

### 第二章 烃

#### 第一节 烷烃

3. **辛烷（汽油成分）的燃烧**  
   2C₈H₁₈ + 25O₂ =点燃= 16CO₂ + 18H₂O
4. **乙烷与氯气反应（生成一氯乙烷）**  
   CH₃CH₃ + Cl₂ =光照= CH₃CH₂Cl + HCl

---

#### 第二节 烯烃 炔烃

5. **乙烯与溴的加成（教材标准方程）**  
   CH₂=CH₂ + Br₂ = CH₂Br-CH₂Br
6. **丙烯与溴的加成**  
   CH₂=CHCH₃ + Br₂ = CH₂Br-CHBrCH₃
7. **乙烯与氯化氢加成（制氯乙烷）**  
   CH₂=CH₂ + HCl =一定条件= CH₃CH₂Cl
8. **丙烯与氯化氢加成（遵循马氏规则，主要产物）**  
   CH₂=CHCH₃ + HCl =一定条件= CH₃CHClCH₃
9. **乙烯与水加成（工业制乙醇）**  
   CH₂=CH₂ + H₂O =催化剂、加热加压= CH₃CH₂OH
10. **丙烯与水加成（主要产物）**  
    CH₂=CHCH₃ + H₂O =催化剂、加热加压= CH₃CH(OH)CH₃
11. **氯乙烯的加聚反应（制聚氯乙烯）**  
    nCH₂=CHCl =一定条件= [-CH₂-CHCl-]ₙ
12. **丙烯的加聚反应（制聚丙烯）**  
    nCH₂=CHCH₃ =一定条件= [-CH₂-CH(CH₃)-]ₙ
13. **异丁烯的加聚反应**  
    nCH₂=C(CH₃)₂ =一定条件= [-CH₂-C(CH₃)₂-]ₙ
14. **电石与水反应（实验室制乙炔）**  
    CaC₂ + 2H₂O = Ca(OH)₂ + CH≡CH↑  
    （注：教材提示用饱和食盐水代替水以减缓反应速率）
15. **乙炔与溴的加成（分步进行）**  
    CH≡CH + Br₂ = CHBr=CHBr  
    CHBr=CHBr + Br₂ = CHBr₂-CHBr₂
16. **乙炔与氢气加成（制乙烯）**  
    CH≡CH + H₂ =Ni、Δ= CH₂=CH₂
17. **乙炔与氯化氢加成（制氯乙烯）**  
    CH≡CH + HCl =催化剂、Δ= CH₂=CHCl
18. **乙炔与水加成（制乙醛）**  
    CH≡CH + H₂O =催化剂、Δ= CH₃CHO  
    （注：实际催化剂常用硫酸汞/硫酸）
19. **乙炔的燃烧**  
    2C₂H₂ + 5O₂ =点燃= 4CO₂ + 2H₂O
20. **1,3-丁二烯与氯气的1,2-加成**  
    CH₂=CH-CH=CH₂ + Cl₂ = CH₂Cl-CHCl-CH=CH₂
21. **1,3-丁二烯与氯气的1,4-加成**  
    CH₂=CH-CH=CH₂ + Cl₂ = CH₂Cl-CH=CH-CH₂Cl

#### 第三节 芳香烃

22. **苯与溴的取代（溴苯）**  
    C₆H₆ + Br₂ =FeBr₃= C₆H₅Br + HBr
23. **苯的硝化反应（硝基苯）**  
    C₆H₆ + HNO₃(浓) =浓H₂SO₄、50～60℃= C₆H₅NO₂ + H₂O
24. **苯的磺化反应（苯磺酸）**  
    C₆H₆ + H₂SO₄(浓) =70～80℃= C₆H₅SO₃H + H₂O
25. **苯与氢气加成（环己烷）**  
    C₆H₆ + 3H₂ =Pt/Ni、Δ= C₆H₁₂
26. **甲苯的硝化（制TNT烈性炸药）**  
    C₆H₅CH₃ + 3HNO₃(浓) =浓H₂SO₄、Δ= C₆H₂(NO₂)₃CH₃ + 3H₂O
27. **甲苯与氯气（光照，侧链取代）**  
    C₆H₅CH₃ + Cl₂ =光照= C₆H₅CH₂Cl + HCl
28. **甲苯与溴（催化，苯环取代）**  
    C₆H₅CH₃ + Br₂ =FeBr₃= C₆H₄BrCH₃ + HBr（生成邻/对-溴甲苯）
29. **甲苯与氢气加成**  
    C₆H₅CH₃ + 3H₂ =Pt、Δ= C₆H₁₁CH₃

### 第三章 烃的衍生物

#### 第一节 卤代烃

30. **溴乙烷的水解（取代反应）**  
    CH₃CH₂Br + NaOH =水、Δ= CH₃CH₂OH + NaBr
31. **溴乙烷的消去反应（制乙烯）**  
    CH₃CH₂Br + NaOH =乙醇、Δ= CH₂=CH₂↑ + NaBr + H₂O
32. **1-溴丁烷的消去反应（课后习题）**  
    CH₃CH₂CH₂CH₂Br + NaOH =乙醇、Δ= CH₃CH₂CH=CH₂↑ + NaBr + H₂O
33. **2-溴丙烷的消去反应（课后习题，制丙烯）**  
    CH₃CHBrCH₃ + NaOH =乙醇、Δ= CH₂=CHCH₃↑ + NaBr + H₂O
34. **四氟乙烯的加聚（制聚四氟乙烯）**  
    nCF₂=CF₂ =一定条件= [-CF₂-CF₂-]ₙ

---

#### 第二节 醇 酚

35. **乙醇与氢溴酸反应（制溴乙烷）**  
    CH₃CH₂OH + HBr =浓H₂SO₄、Δ= CH₃CH₂Br + H₂O
36. **乙醇的消去反应（制乙烯）**  
    CH₃CH₂OH =浓H₂SO₄、170℃= CH₂=CH₂↑ + H₂O  
    （注：必须迅速升温至170℃）
37. **乙醇分子间脱水（制乙醚）**  
    2CH₃CH₂OH =浓H₂SO₄、140℃= CH₃CH₂OCH₂CH₃ + H₂O
38. **乙醇的催化氧化（制乙醛）**  
    2CH₃CH₂OH + O₂ =Cu/Ag、Δ= 2CH₃CHO + 2H₂O
39. **乙醇与酸性重铬酸钾反应（总反应，教材描述性）**  
    3CH₃CH₂OH + 2K₂Cr₂O₇ + 8H₂SO₄ = 3CH₃COOH + 2Cr₂(SO₄)₃ + 2K₂SO₄ + 11H₂O  
    （注：教材为文字描述，此配平式供参考）
40. **苯酚与氢氧化钠（苯酚的酸性）**  
    C₆H₅OH + NaOH = C₆H₅ONa + H₂O
41. **苯酚钠与盐酸（复分解）**  
    C₆H₅ONa + HCl = C₆H₅OH + NaCl
42. **苯酚钠与二氧化碳（苯酚酸性弱于碳酸）**  
    C₆H₅ONa + CO₂ + H₂O = C₆H₅OH + NaHCO₃  
    （注：无论CO₂多少，产物均为NaHCO₃）
43. **苯酚的取代反应（与溴水，检验苯酚）**  
    C₆H₅OH + 3Br₂ = C₆H₂Br₃OH↓ + 3HBr（生成2,4,6-三溴苯酚白色沉淀）

---

#### 第三节 醛 酮

44. **乙醛的催化加氢（还原成乙醇）**  
    CH₃CHO + H₂ =Ni、Δ= CH₃CH₂OH
45. **乙醛与氰化氢加成（增长碳链）**  
    CH₃CHO + HCN =催化剂(痕量碱)= CH₃CH(OH)CN（2-羟基丙腈）
46. **乙醛的银镜反应**  
    CH₃CHO + 2[Ag(NH₃)₂]OH =水浴加热= CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O
47. **乙醛与新制氢氧化铜反应**  
    CH₃CHO + 2Cu(OH)₂ + NaOH =Δ= CH₃COONa + Cu₂O↓ + 3H₂O
48. **乙醛的催化氧化（制乙酸）**  
    2CH₃CHO + O₂ =催化剂、Δ= 2CH₃COOH
49. **丙酮与氢气加成（制2-丙醇）**  
    CH₃COCH₃ + H₂ =Ni、Δ= CH₃CH(OH)CH₃

---

#### 第四节 羧酸 羧酸衍生物

50. **乙酸与乙醇的酯化反应（可逆）**  
    CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O（Δ、浓H₂SO₄）  
    （注：用同位素示踪证明是酸脱羟基、醇脱氢）
51. **乙酸乙酯在酸性条件下的水解（可逆）**  
    CH₃COOC₂H₅ + H₂O ⇌ CH₃COOH + C₂H₅OH（Δ、稀H₂SO₄）
52. **乙酸乙酯在碱性条件下的水解（不可逆）**  
    CH₃COOC₂H₅ + NaOH =Δ= CH₃COONa + C₂H₅OH
53. **油脂的皂化反应（硬脂酸甘油酯水解）**  
    (C₁₇H₃₅COO)₃C₃H₅ + 3NaOH =Δ= 3C₁₇H₃₅COONa + C₃H₅(OH)₃
54. **油酸甘油酯的氢化（油脂硬化）**  
    (C₁₇H₃₃COO)₃C₃H₅ + 3H₂ =Ni、Δ= (C₁₇H₃₅COO)₃C₃H₅
55. **酰胺在酸性条件下的水解**  
    RCONH₂ + HCl + H₂O =Δ= RCOOH + NH₄Cl
56. **酰胺在碱性条件下的水解**  
    RCONH₂ + NaOH =Δ= RCOONa + NH₃↑

---

#### 第五节 有机合成（经典路线方程）

57. **乙烯与氯气加成（制1,2-二氯乙烷）**  
    CH₂=CH₂ + Cl₂ = CH₂ClCH₂Cl
58. **1,2-二氯乙烷水解（制乙二醇）**  
    CH₂ClCH₂Cl + 2NaOH =水、Δ= CH₂OHCH₂OH + 2NaCl
59. **乙二醇氧化（制乙二酸/草酸）**  
    CH₂OHCH₂OH + 2O₂ =催化剂、Δ= HOOC-COOH + 2H₂O
60. **乙烯水化（制乙醇）**  
    CH₂=CH₂ + H₂O =催化剂、加热加压= CH₃CH₂OH
61. **乙二酸与乙醇酯化（制乙二酸二乙酯）**  
    HOOC-COOH + 2C₂H₅OH ⇌ C₂H₅OOC-COOC₂H₅ + 2H₂O（Δ、浓H₂SO₄）
62. **环氧乙烷与水加成（工业制乙二醇）**  
    C₂H₄O + H₂O = HOCH₂CH₂OH

### 第四章 生物大分子

#### 第一节 糖类

63. **葡萄糖在人体内的氧化（供能）**  
    C₆H₁₂O₆ + 6O₂ =酶= 6CO₂ + 6H₂O
64. **蔗糖水解（生成葡萄糖和果糖）**  
    C₁₂H₂₂O₁₁ + H₂O =酸或酶= C₆H₁₂O₆ + C₆H₁₂O₆
65. **麦芽糖水解（只生成葡萄糖）**  
    C₁₂H₂₂O₁₁ + H₂O =酸或酶= 2C₆H₁₂O₆
66. **淀粉水解（最终产物为葡萄糖）**  
    (C₆H₁₀O₅)ₙ + nH₂O =酸或酶= nC₆H₁₂O₆
67. **纤维素水解**  
    (C₆H₁₀O₅)ₙ + nH₂O =酸或酶= nC₆H₁₂O₆

---

#### 第二节 蛋白质（氨基酸性质）

68. **氨基酸与盐酸反应（表现碱性）**  
    RCH(NH₂)COOH + HCl = RCH(NH₃Cl)COOH
69. **氨基酸与氢氧化钠反应（表现酸性）**  
    RCH(NH₂)COOH + NaOH = RCH(NH₂)COONa + H₂O
70. **氨基酸的成肽反应（通式，生成二肽）**  
    2H₂N-CH(R)-COOH =一定条件= H₂N-CH(R)-CONH-CH(R)-COOH + H₂O

---

### 第五章 合成高分子

#### 第一节 & 第二节（聚合反应）

71. **1,3-丁二烯聚合（制顺丁橡胶）**  
    nCH₂=CH-CH=CH₂ =催化剂= [-CH₂-CH=CH-CH₂-]ₙ
72. **己二酸与乙二醇缩聚（制聚酯）**  
    nHOOC-(CH₂)₄-COOH + nHOCH₂CH₂OH ⇌ [-OC-(CH₂)₄-COOCH₂CH₂O-]ₙ + (2n-1)H₂O（Δ）
73. **苯酚与甲醛缩聚（制线型酚醛树脂）**  
    nC₆H₅OH + nHCHO =酸或碱、Δ= [-C₆H₃(OH)-CH₂-]ₙ + (n-1)H₂O
74. **对苯二甲酸与乙二醇缩聚（制涤纶）**  
    nHOOC-C₆H₄-COOH + nHOCH₂CH₂OH =催化剂、Δ= [-OC-C₆H₄-COOCH₂CH₂O-]ₙ + (2n-1)H₂O
75. **己二胺与己二酸缩聚（制锦纶66）**  
    nH₂N-(CH₂)₆-NH₂ + nHOOC-(CH₂)₄-COOH =Δ= [-NH-(CH₂)₆-NHCO-(CH₂)₄-CO-]ₙ + (2n-1)H₂O
