### 一、热化学方程式（含ΔH）

1. H₂(g) + Cl₂(g) = 2HCl(g)　ΔH = -184.6 kJ/mol
2. C(s) + H₂O(g) = CO(g) + H₂(g)　ΔH = +131.5 kJ/mol
3. H₂(g) + ½O₂(g) = H₂O(g)　ΔH = -241.8 kJ/mol
4. H₂(g) + ½O₂(g) = H₂O(l)　ΔH = -285.8 kJ/mol
5. ½H₂(g) + ½Cl₂(g) = HCl(g)　ΔH = -92.3 kJ/mol
6. C(s) + O₂(g) = CO₂(g)　ΔH = -393.5 kJ/mol
7. C₈H₁₈(l) + ²⁵⁄₂O₂(g) = 8CO₂(g) + 9H₂O(l)　ΔH = -5471 kJ/mol
8. CH₄(g) + 2O₂(g) = CO₂(g) + 2H₂O(l)　ΔH = -890.3 kJ/mol
9. CH₃(CH₂)₁₄COOH(s) + 23O₂(g) = 16CO₂(g) + 16H₂O(l)　ΔH = -9977 kJ/mol
10. CO(g) + ½O₂(g) = CO₂(g)　ΔH = -283.0 kJ/mol
11. C(s) + ½O₂(g) = CO(g)　ΔH = -110.5 kJ/mol
12. FeS₂(s) + ¹¹⁄₄O₂(g) = ½Fe₂O₃(s) + 2SO₂(g)　ΔH = -853 kJ/mol
13. C₆H₁₂O₆(s) + 6O₂(g) = 6CO₂(g) + 6H₂O(l)　ΔH = -2800 kJ/mol
14. CH₄(g) + H₂O(g) = CO(g) + 3H₂(g)　ΔH = +205.9 kJ/mol
15. CH₄(g) = C(s) + 2H₂(g)　ΔH = +74.4 kJ/mol
16. 2NO₂(g) ⇌ N₂O₄(g)　ΔH = -56.9 kJ/mol

### 四、原电池电极反应与总反应

38. **锌铜原电池**：负极：Zn – 2e⁻ = Zn²⁺；正极：Cu²⁺ + 2e⁻ = Cu；总：Zn + Cu²⁺ = Zn²⁺ + Cu
39. **碱性锌锰电池**

    - 负极：Zn + 2OH⁻ – 2e⁻ = Zn(OH)₂
    - 正极：MnO₂ + H₂O + e⁻ = MnO(OH) + OH⁻
    - 总：Zn + 2MnO₂ + 2H₂O = 2MnO(OH) + Zn(OH)₂
40. **铅蓄电池**

    - 负极：Pb + SO₄²⁻ – 2e⁻ = PbSO₄
    - 正极：PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O
    - 总：Pb + PbO₂ + 2H₂SO₄ = 2PbSO₄ + 2H₂O
41. **锂离子电池（放电）**

    - 负极：LiₓCᵧ – xe⁻ = xLi⁺ + Cᵧ
    - 正极：Li₁₋ₓCoO₂ + xLi⁺ + xe⁻ = LiCoO₂
42. **氢氧燃料电池（酸性）**

    - 负极：H₂ – 2e⁻ = 2H⁺
    - 正极：O₂ + 4H⁺ + 4e⁻ = 2H₂O
    - 总：2H₂ + O₂ = 2H₂O

### 五、电解池电极反应与总反应（均需"电解"条件）

43. **电解CuCl₂溶液**

    - 阳极：2Cl⁻ – 2e⁻ = Cl₂↑
    - 阴极：Cu²⁺ + 2e⁻ = Cu
    - 总：Cu²⁺ + 2Cl⁻ = Cu + Cl₂↑（电解）
44. **电解饱和食盐水**

    - 阳极：2Cl⁻ – 2e⁻ = Cl₂↑
    - 阴极：2H₂O + 2e⁻ = H₂↑ + 2OH⁻
    - 总：2Cl⁻ + 2H₂O = Cl₂↑ + H₂↑ + 2OH⁻（电解）  
      （或 2NaCl + 2H₂O = 2NaOH + H₂↑ + Cl₂↑，电解）
45. **电解熔融NaCl**

    - 阳极：2Cl⁻ – 2e⁻ = Cl₂↑
    - 阴极：Na⁺ + e⁻ = Na
    - 总：2NaCl(熔融) = 2Na + Cl₂↑（电解）
46. **电有机合成（己二腈）**

    - 阳极：H₂O – 2e⁻ = ½O₂↑ + 2H⁺
    - 阴极：2CH₂=CHCN + 2H⁺ + 2e⁻ = NC(CH₂)₄CN
    - 总：2CH₂=CHCN + H₂O = NC(CH₂)₄CN + ½O₂↑（电解）

### 六、金属腐蚀电极反应

47. **析氢腐蚀**（酸性）

    - 负极：Fe – 2e⁻ = Fe²⁺
    - 正极：2H⁺ + 2e⁻ = H₂↑
    - 总：Fe + 2H⁺ = Fe²⁺ + H₂↑
48. **吸氧腐蚀**（中性或弱酸性）

    - 负极：Fe – 2e⁻ = Fe²⁺
    - 正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻
    - 总：2Fe + O₂ + 2H₂O = 2Fe(OH)₂
    - 后续：4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃
