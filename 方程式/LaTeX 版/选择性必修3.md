#### 第二节 烯烃 炔烃

5. **乙烯与溴的加成（教材标准方程）**  
   \(\mathrm{CH_2=CH_2 + Br_2 = CH_2Br-CH_2Br}\)
6. **丙烯与溴的加成**  
   \(\mathrm{CH_2=CHCH_3 + Br_2 = CH_2Br-CHBrCH_3}\)
7. **乙烯与氯化氢加成（制氯乙烷）**  
   \(\mathrm{CH_2=CH_2 + HCl \xlongequal{一定条件} CH_3CH_2Cl}\)
8. **丙烯与氯化氢加成（遵循马氏规则，主要产物）**  
   \(\mathrm{CH_2=CHCH_3 + HCl \xlongequal{一定条件} CH_3CHClCH_3}\)
9. **乙烯与水加成（工业制乙醇）**  
   \(\mathrm{CH_2=CH_2 + H_2O \xlongequal{催化剂、加热加压} CH_3CH_2OH}\)
10. **丙烯与水加成（主要产物）**  
    \(\mathrm{CH_2=CHCH_3 + H_2O \xlongequal{催化剂、加热加压} CH_3CH(OH)CH_3}\)
11. **氯乙烯的加聚反应（制聚氯乙烯）**  
    \(\mathrm{nCH_2=CHCl \xlongequal{一定条件} [-CH_2-CHCl-]_n}\)
12. **丙烯的加聚反应（制聚丙烯）**  
    \(\mathrm{nCH_2=CHCH_3 \xlongequal{一定条件} [-CH_2-CH(CH_3)-]_n}\)
13. **异丁烯的加聚反应**  
    \(\mathrm{nCH_2=C(CH_3)_2 \xlongequal{一定条件} [-CH_2-C(CH_3)_2-]_n}\)
14. **电石与水反应（实验室制乙炔）**  
    \(\mathrm{CaC_2 + 2H_2O = Ca(OH)_2 + CH\equiv CH\uparrow}\)  
    （注：教材提示用饱和食盐水代替水以减缓反应速率）
15. **乙炔与溴的加成（分步进行）**  
    \(\mathrm{CH\equiv CH + Br_2 = CHBr=CHBr}\)  
    \(\mathrm{CHBr=CHBr + Br_2 = CHBr_2-CHBr_2}\)
16. **乙炔与氢气加成（制乙烯）**  
    \(\mathrm{CH\equiv CH + H_2 \xlongequal{Ni、\Delta} CH_2=CH_2}\)
17. **乙炔与氯化氢加成（制氯乙烯）**  
    \(\mathrm{CH\equiv CH + HCl \xlongequal{催化剂、\Delta} CH_2=CHCl}\)
18. **乙炔与水加成（制乙醛）**  
    \(\mathrm{CH\equiv CH + H_2O \xlongequal{催化剂、\Delta} CH_3CHO}\)  
    （注：实际催化剂常用硫酸汞/硫酸）
19. **乙炔的燃烧**  
    \(\mathrm{2C_2H_2 + 5O_2 \xlongequal{点燃} 4CO_2 + 2H_2O}\)
20. **1,3-丁二烯与氯气的1,2-加成**  
    \(\mathrm{CH_2=CH-CH=CH_2 + Cl_2 = CH_2Cl-CHCl-CH=CH_2}\)
21. **1,3-丁二烯与氯气的1,4-加成**  
    \(\mathrm{CH_2=CH-CH=CH_2 + Cl_2 = CH_2Cl-CH=CH-CH_2Cl}\)

#### 第三节 芳香烃

22. **苯与溴的取代（溴苯）**

    \(\mathrm{C_6H_6 + 3H_2 \xlongequal{Pt/Ni、\Delta} C_6H_{12}}\)
26. **甲苯的硝化（制TNT烈性炸药）**  
    \(\mathrm{C_6H_5CH_3 + 3HNO_3(浓) \xlongequal{浓H_2SO_4、\Delta} C_6H_2(NO_2)_3CH_3 + 3H_2O}\)
27. **甲苯与氯气（光照，侧链取代）**  
    \(\mathrm{C_6H_5CH_3 + Cl_2 \xlongequal{光照} C_6H_5CH_2Cl + HCl}\)
28. **甲苯与溴（催化，苯环取代）**

### 第三章 烃的衍生物

#### 第一节 卤代烃

30. **溴乙烷的水解（取代反应）**  
    \(\mathrm{CH_3CH_2Br + NaOH \xlongequal{水、\Delta} CH_3CH_2OH + NaBr}\)
31. **溴乙烷的消去反应（制乙烯）**  
    \(\mathrm{CH_3CH_2Br + NaOH \xlongequal{乙醇、\Delta} CH_2=CH_2\uparrow + NaBr + H_2O}\)
32. **1-溴丁烷的消去反应（课后习题）**  
    \(\mathrm{CH_3CH_2CH_2CH_2Br + NaOH \xlongequal{乙醇、\Delta} CH_3CH_2CH=CH_2\uparrow + NaBr + H_2O}\)
33. **2-溴丙烷的消去反应（课后习题，制丙烯）**  
    \(\mathrm{CH_3CHBrCH_3 + NaOH \xlongequal{乙醇、\Delta} CH_2=CHCH_3\uparrow + NaBr + H_2O}\)
34. **四氟乙烯的加聚（制聚四氟乙烯）**  
    \(\mathrm{nCF_2=CF_2 \xlongequal{一定条件} [-CF_2-CF_2-]_n}\)

---

#### 第二节 醇 酚

35. **乙醇与氢溴酸反应（制溴乙烷）**  
    \(\mathrm{CH_3CH_2OH + HBr \xlongequal{浓H_2SO_4、\Delta} CH_3CH_2Br + H_2O}\)
36. **乙醇的消去反应（制乙烯）**  
    \(\mathrm{CH_3CH_2OH \xlongequal{浓H_2SO_4、170℃} CH_2=CH_2\uparrow + H_2O}\)  
    （注：必须迅速升温至170℃）
37. **乙醇分子间脱水（制乙醚）**  
    \(\mathrm{2CH_3CH_2OH \xlongequal{浓H_2SO_4、140℃} CH_3CH_2OCH_2CH_3 + H_2O}\)
38. **乙醇的催化氧化（制乙醛）**  
    \(\mathrm{2CH_3CH_2OH + O_2 \xlongequal{Cu/Ag、\Delta} 2CH_3CHO + 2H_2O}\)
39. **乙醇与酸性重铬酸钾反应（总反应，教材描述性）**  
    \(\mathrm{3CH_3CH_2OH + 2K_2Cr_2O_7 + 8H_2SO_4 = 3CH_3COOH + 2Cr_2(SO_4)_3 + 2K_2SO_4 + 11H_2O}\)  
    （注：教材为文字描述，此配平式供参考）
40. **苯酚与氢氧化钠（苯酚的酸性）**  
    \(\mathrm{C_6H_5OH + NaOH = C_6H_5ONa + H_2O}\)
41. **苯酚钠与盐酸（复分解）**  
    \(\mathrm{C_6H_5ONa + HCl = C_6H_5OH + NaCl}\)
42. **苯酚钠与二氧化碳（苯酚酸性弱于碳酸）**  
    \(\mathrm{C_6H_5ONa + CO_2 + H_2O = C_6H_5OH + NaHCO_3}\)  
    （注：无论CO₂多少，产物均为NaHCO₃）
43. **苯酚的取代反应（与溴水，检验苯酚）**  
    \(\mathrm{C_6H_5OH + 3Br_2 = C_6H_2Br_3OH\downarrow + 3HBr}\)（生成2,4,6-三溴苯酚白色沉淀）

---

#### 第三节 醛 酮

44. **乙醛的催化加氢（还原成乙醇）**  
    \(\mathrm{CH_3CHO + H_2 \xlongequal{Ni、\Delta} CH_3CH_2OH}\)
45. **乙醛与氰化氢加成（增长碳链）**  
    \(\mathrm{CH_3CHO + HCN \xlongequal{催化剂(痕量碱)} CH_3CH(OH)CN}\)（2-羟基丙腈）
46. **乙醛的银镜反应**  
    \(\mathrm{CH_3CHO + 2[Ag(NH_3)_2]OH \xlongequal{水浴加热} CH_3COONH_4 + 2Ag\downarrow + 3NH_3 + H_2O}\)
47. **乙醛与新制氢氧化铜反应**  
    \(\mathrm{CH_3CHO + 2Cu(OH)_2 + NaOH \xlongequal{\Delta} CH_3COONa + Cu_2O\downarrow + 3H_2O}\)
48. **乙醛的催化氧化（制乙酸）**  
    \(\mathrm{2CH_3CHO + O_2 \xlongequal{催化剂、\Delta} 2CH_3COOH}\)
49. **丙酮与氢气加成（制2-丙醇）**  
    \(\mathrm{CH_3COCH_3 + H_2 \xlongequal{Ni、\Delta} CH_3CH(OH)CH_3}\)

#### 第四节 羧酸 羧酸衍生物

50. **乙酸与乙醇的酯化反应（可逆）**  
    \(\mathrm{CH_3COOH + C_2H_5OH \xrightleftharpoons[浓H_2SO_4]{\Delta} CH_3COOC_2H_5 + H_2O}\)  
    （注：用同位素示踪证明是酸脱羟基、醇脱氢）
51. **乙酸乙酯在酸性条件下的水解（可逆）**  
    \(\mathrm{CH_3COOC_2H_5 + H_2O \xrightleftharpoons[稀H_2SO_4]{\Delta} CH_3COOH + C_2H_5OH}\)
52. **乙酸乙酯在碱性条件下的水解（不可逆）**  
    \(\mathrm{CH_3COOC_2H_5 + NaOH \xlongequal{\Delta} CH_3COONa + C_2H_5OH}\)
53. **油脂的皂化反应（硬脂酸甘油酯水解）**  
    \(\mathrm{(C_{17}H_{35}COO)_3C_3H_5 + 3NaOH \xlongequal{\Delta} 3C_{17}H_{35}COONa + C_3H_5(OH)_3}\)
54. **油酸甘油酯的氢化（油脂硬化）**  
    \(\mathrm{(C_{17}H_{33}COO)_3C_3H_5 + 3H_2 \xlongequal{Ni、\Delta} (C_{17}H_{35}COO)_3C_3H_5}\)
55. **酰胺在酸性条件下的水解**  
    \(\mathrm{RCONH_2 + HCl + H_2O \xlongequal{\Delta} RCOOH + NH_4Cl}\)
56. **酰胺在碱性条件下的水解**  
    \(\mathrm{RCONH_2 + NaOH \xlongequal{\Delta} RCOONa + NH_3\uparrow}\)

### 第五章 合成高分子

#### 第一节 & 第二节（聚合反应）
