# 化学方程式整理 · 勘误说明

> 本文件记录 5 份方程式文件的统一整理与修正内容，供追溯核对。
> 源文件位于 `化学方程式可视化/方程式/`，整理后输出至 `化学方程式可视化/` 根目录（同名文件，原文件未改动）。

## 一、格式统一约定

| 项目 | 约定 |
|---|---|
| 方程载体 | 统一行内 LaTeX：`\(\mathrm{...}\)`（原选择性必修2 的显示块 `\[...\]` 一并改为行内） |
| 离子电荷 | `^{n+}` / `^{n-}`，如 `Ba^{2+}`、`Cl^-` |
| 反应条件 | 单条件 `\xrightarrow{条件}`；可逆带条件 `\xrightleftharpoons[下方条件]{上方条件}` |
| 条件书写 | 中文直接写入（去 `\text{}` 包裹），多条件用顿号，如 `\xrightarrow{催化剂、加热加压}` |
| 气体 / 沉淀 | `\uparrow` / `\downarrow` |
| 加热 | `\Delta` |
| 分数系数 | `\frac{分子}{分母}` |
| 加聚产物 | 统一 `[-CH_2-CH_2-]_n` 形式（原 `\mathop{[...]}\limits_{n}` 简写） |
| 状态与备注 | `(s)(l)(g)(aq)`、中文备注保留在方程外括号 |

## 二、逐文件修改记录

### 必修1.md（原 Unicode 文本 → LaTeX）

- **37 号 火法炼锌（化学修正）**：原式 `ZnCO₃ + C —高温→ Zn + CO↑` 配平错误（O 不守恒，左 3 右 1）。改为实际两步反应：
  - `ZnCO₃ —高温→ ZnO + CO₂↑`（菱锌矿分解）
  - `ZnO + C —高温→ Zn + CO↑`（碳还原）
- 其余 70 条：仅格式转换（Unicode 下标/上标 → LaTeX、`—高温→` 等 → `\xrightarrow{...}`、`⇌` → `\rightleftharpoons`），化学内容不变。

### 必修2.md（LaTeX 修复）

- **11 号（格式修复）**：`Ba<sup>{2+} + SO_4</sup>{2-}` HTML 标签残留 → `Ba^{2+} + SO_4^{2-}`
- **17 号（格式修复）**：`NH_4<sup>+ + OH</sup>-` → `NH_4^+ + OH^-`
- **32 号（格式修复）**：负极 `Zn - 2e<sup>- = Zn</sup>{2+}` → `Zn - 2e^- = Zn^{2+}`；正极 `2H<sup>+ + 2e</sup>- = H_2\uparrow` → `2H^+ + 2e^- = H_2\uparrow`
- 6、14、47 号：条件中 `\text{}` 包裹去除（`\xrightleftharpoons[\text{催化剂}]{\Delta}` → `\xrightleftharpoons[催化剂]{\Delta}`）
- 43 号：加聚写法统一 `-[CH_2-CH_2]-_n` → `[-CH_2-CH_2-]_n`
- 其余：化学内容不变。

### 选择性必修1.md（原 Unicode 文本 → LaTeX）

- 分数系数转换：`½`、`²⁵⁄₂`、`¹¹⁄₄` → `\frac{1}{2}`、`\frac{25}{2}`、`\frac{11}{4}`
- ΔH 统一为 LaTeX：`\quad \Delta H = -5471\ \mathrm{kJ/mol}`，原数字千位空格（如 `5 471`、`9 977`、`2 800`）去除
- 38 号 补电池名称"锌铜原电池"（原文该条仅有电极式，与原目录标题对齐）
- 其余：格式转换，化学内容不变。

### 选择性必修2.md（LaTeX 修复）

- **2 号（格式修复）**：`Cu<sup>{2+}}` / `NH_4</sup>+` HTML 残留 → `Cu^{2+}` / `NH_4^+`
- **5 号（格式修复）**：`I<sup>-}` / `I_3</sup>-` → `I^-` / `I_3^-`
- 显示块 `\[...\]` → 行内 `\(\mathrm{...}\)`；`\text{点燃}` → `\xrightarrow{点燃}`
- 化学内容不变。

### 选择性必修3.md（LaTeX 清理统一）

- 全部 `\xrightarrow[]{条件}` 空参数括号去除 → `\xrightarrow{条件}`
- 条件内 `,\ `（半角逗号）→ 顿号（如 `催化剂、加热加压`）
- 加聚产物统一：`\mathop{[-CH_2-CHCl-]}\limits_{n}` → `[-CH_2-CHCl-]_n`（11、12、13、34、71–75 号）
- **26 号（表示法统一）**：中文式 `甲苯 + 3HNO₃(浓) → 2,4,6-三硝基甲苯(TNT) + 3H₂O` → 化学式 `C₆H₅CH₃ + 3HNO₃(浓) → C₆H₂(NO₂)₃CH₃ + 3H₂O`（"制TNT"信息保留在条目标题）
- **28 号（表示法统一）**：产物 `邻/对-溴甲苯` → `C₆H₄BrCH₃`（中文名移至括号备注）
- **29 号（表示法统一）**：产物 `甲基环己烷` → `C₆H₁₁CH₃`
- **62 号（表示法统一）**：反应物 `环氧乙烷` → `C₂H₄O`
- **64 号**：式内 `(葡萄糖)`/`(果糖)` 中文标注移出（条目标题已注明"生成葡萄糖和果糖"）
- 注释格式统一为 `（注：...）`（原 `(*注：...*)` 混用）

## 三、化学正确性复核结论

转换与修复过程中逐条复核了配平与产物，**除必修1 第 37 号外未发现其他化学错误**（含 39 号乙醇与重铬酸钾总反应、各电池/电解池电极反应等复杂式的原子守恒与电荷守恒复核）。

## 四、审查后追加修改（交叉审查发现）

经 3 个子代理并行交叉审查（无机 / 电化学平衡 / 有机三组）后，追加以下修正：

| 位置 | 修改内容 | 原因 |
|---|---|---|
| 必修1 #22 | `WO₃ + 3H₂ = W + 3H₂O` 补条件 → `\xrightarrow{高温}` | 氢还原氧化钨必须高温，原式缺反应条件 |
| 必修1 #69 | `H₂ + I₂ \xrightarrow{\Delta}` → `H₂ + I₂ \xrightleftharpoons{\Delta}` | 该化合反应可逆（教材明确标注），改为可逆符号 |
| 必修2 #27 / #28 | `300^\circ C`、`1100^\circ C` → `300^{\circ}C`、`1100^{\circ}C` | LaTeX 规范：`\circ` 以上标形式书写 |
| 必修2 #58 | `WO₃ + 3H₂ \xrightarrow{\Delta}` → `\xrightarrow{高温}` | 与必修1 #22 为同一反应，统一条件标注 |
| 选择性必修1 #48 | 删除总反应行尾多余半角 `)` | 排版笔误，`\)` 闭合后残留一个 `)` |

其余 210 条方程式经三组交叉审查**未发现化学错误与格式问题**。
