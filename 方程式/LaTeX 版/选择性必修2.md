# 选择性必修2

**1. 镁在二氧化碳中燃烧**  
\(\mathrm{2Mg + CO_2 \xlongequal{点燃} 2MgO + C}\)

**2. 硫酸铜溶液中滴加氨水（生成氢氧化铜沉淀）**  
\(\mathrm{Cu^{2+} + 2NH_3\cdot H_2O = Cu(OH)_2\downarrow + 2NH_4^+}\)

**3. 氢氧化铜沉淀溶于过量氨水（生成铜氨配合物）**  
\(\mathrm{Cu(OH)_2 + 4NH_3 = [Cu(NH_3)_4](OH)_2}\)

**4. 氯化银沉淀溶于氨水（生成银氨配合物）**  
\(\mathrm{AgCl + 2NH_3 = [Ag(NH_3)_2]Cl}\)

**5. 碘单质与碘离子反应（生成三碘离子）**  
\(\mathrm{I_2 + I^- \rightleftharpoons I_3^-}\)
