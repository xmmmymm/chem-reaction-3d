### 四、原电池电极反应与总反应

38. **锌铜原电池**：负极：\(\mathrm{Zn - 2e^- = Zn^{2+}}\)；正极：\(\mathrm{Cu^{2+} + 2e^- = Cu}\)；总：\(\mathrm{Zn + Cu^{2+} = Zn^{2+} + Cu}\)
39. **碱性锌锰电池**

    - 负极：\(\mathrm{Zn + 2OH^- - 2e^- = Zn(OH)_2}\)
    - 正极：\(\mathrm{MnO_2 + H_2O + e^- = MnO(OH) + OH^-}\)
    - 总：\(\mathrm{Zn + 2MnO_2 + 2H_2O = 2MnO(OH) + Zn(OH)_2}\)
40. **铅蓄电池**

    - 负极：\(\mathrm{Pb + SO_4^{2-} - 2e^- = PbSO_4}\)
    - 正极：\(\mathrm{PbO_2 + 4H^+ + SO_4^{2-} + 2e^- = PbSO_4 + 2H_2O}\)
    - 总：\(\mathrm{Pb + PbO_2 + 2H_2SO_4 = 2PbSO_4 + 2H_2O}\)
41. **锂离子电池（放电）**

    - 负极：\(\mathrm{Li_xC_y - xe^- = xLi^+ + C_y}\)
    - 正极：\(\mathrm{Li_{1-x}CoO_2 + xLi^+ + xe^- = LiCoO_2}\)
42. **氢氧燃料电池（酸性）**

    - 负极：\(\mathrm{H_2 - 2e^- = 2H^+}\)
    - 正极：\(\mathrm{O_2 + 4H^+ + 4e^- = 2H_2O}\)
    - 总：\(\mathrm{2H_2 + O_2 = 2H_2O}\)

### 五、电解池电极反应与总反应（均需"电解"条件）

43. **电解CuCl₂溶液**

    - 阳极：\(\mathrm{2Cl^- - 2e^- = Cl_2\uparrow}\)
    - 阴极：\(\mathrm{Cu^{2+} + 2e^- = Cu}\)
    - 总：\(\mathrm{Cu^{2+} + 2Cl^- = Cu + Cl_2\uparrow}\)（电解）
44. **电解饱和食盐水**

    - 阳极：\(\mathrm{2Cl^- - 2e^- = Cl_2\uparrow}\)
    - 阴极：\(\mathrm{2H_2O + 2e^- = H_2\uparrow + 2OH^-}\)
    - 总：\(\mathrm{2Cl^- + 2H_2O = Cl_2\uparrow + H_2\uparrow + 2OH^-}\)（电解）  
      （或 \(\mathrm{2NaCl + 2H_2O = 2NaOH + H_2\uparrow + Cl_2\uparrow}\)，电解）
45. **电解熔融NaCl**

    - 阳极：\(\mathrm{2Cl^- - 2e^- = Cl_2\uparrow}\)
    - 阴极：\(\mathrm{Na^+ + e^- = Na}\)
    - 总：\(\mathrm{2NaCl(熔融) = 2Na + Cl_2\uparrow}\)（电解）
46. **电有机合成（己二腈）**

    - 阳极：\(\mathrm{H_2O - 2e^- = \frac{1}{2}O_2\uparrow + 2H^+}\)
    - 阴极：\(\mathrm{2CH_2=CHCN + 2H^+ + 2e^- = NC(CH_2)_4CN}\)
    - 总：\(\mathrm{2CH_2=CHCN + H_2O = NC(CH_2)_4CN + \frac{1}{2}O_2\uparrow}\)（电解）

---

### 六、金属腐蚀电极反应

47. **析氢腐蚀**（酸性）

    - 负极：\(\mathrm{Fe - 2e^- = Fe^{2+}}\)
    - 正极：\(\mathrm{2H^+ + 2e^- = H_2\uparrow}\)
    - 总：\(\mathrm{Fe + 2H^+ = Fe^{2+} + H_2\uparrow}\)
48. **吸氧腐蚀**（中性或弱酸性）

    - 负极：\(\mathrm{Fe - 2e^- = Fe^{2+}}\)
    - 正极：\(\mathrm{O_2 + 2H_2O + 4e^- = 4OH^-}\)
    - 总：\(\mathrm{2Fe + O_2 + 2H_2O = 2Fe(OH)_2}\)
    - 后续：\(\mathrm{4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3}\)
