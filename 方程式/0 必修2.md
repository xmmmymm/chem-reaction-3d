### 一、硫及其化合物

1. S + Fe =Δ= FeS
2. S + 2Cu =Δ= Cu₂S
3. S + H₂ =Δ= H₂S
4. S + O₂ =点燃= SO₂
5. SO₂ + H₂O ⇌ H₂SO₃
6. 2SO₂ + O₂ ⇌ 2SO₃（Δ、催化剂）
7. SO₃ + H₂O = H₂SO₄
8. SO₂ + 2H₂S = 3S + 2H₂O
9. 2H₂SO₄(浓) + Cu =Δ= CuSO₄ + SO₂↑ + 2H₂O
10. 2H₂SO₄(浓) + C =Δ= CO₂↑ + 2SO₂↑ + 2H₂O
11. Ba²⁺ + SO₄²⁻ = BaSO₄↓

### 二、氮及其化合物

12. N₂ + 3Mg =点燃= Mg₃N₂
13. N₂ + O₂ =放电或高温= 2NO
14. N₂ + 3H₂ ⇌ 2NH₃（高温、高压、催化剂）
15. 2NO + O₂ = 2NO₂
16. 3NO₂ + H₂O = 2HNO₃ + NO
17. NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻
18. NH₃ + HCl = NH₄Cl
19. 4NH₃ + 5O₂ =催化剂= 4NO + 6H₂O
20. NH₄Cl =Δ= NH₃↑ + HCl↑
21. NH₄HCO₃ =Δ= NH₃↑ + H₂O + CO₂↑
22. 2NH₄Cl + Ca(OH)₂ =Δ= CaCl₂ + 2NH₃↑ + 2H₂O
23. 4HNO₃ =Δ或光照= 4NO₂↑ + O₂↑ + 2H₂O
24. 4HNO₃(浓) + Cu = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
25. 8HNO₃(稀) + 3Cu = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O

37. CH₄ + 2O₂ =点燃= CO₂ + 2H₂O
38. C₃H₈ + 5O₂ =点燃= 3CO₂ + 4H₂O
