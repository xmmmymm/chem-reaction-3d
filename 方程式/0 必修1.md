# 必修1

### 一、电离方程式（酸、碱、盐溶于水）

1. NaCl = Na⁺ + Cl⁻
2. KNO₃ = K⁺ + NO₃⁻
3. HCl = H⁺ + Cl⁻
4. H₂SO₄ = 2H⁺ + SO₄²⁻
5. HNO₃ = H⁺ + NO₃⁻

---

### 二、离子反应与复分解反应（含离子方程式）

6. Na₂SO₄ + BaCl₂ = 2NaCl + BaSO₄↓
7. Ba²⁺ + SO₄²⁻ = BaSO₄↓
8. H⁺ + OH⁻ = H₂O
9. Zn + 2H⁺ = Zn²⁺ + H₂↑
10. Fe + Cu²⁺ = Cu + Fe²⁺
11. CO₃²⁻ + 2H⁺ = H₂O + CO₂↑
12. Cu²⁺ + 2OH⁻ = Cu(OH)₂↓
13. Cu + 2Ag⁺ = Cu²⁺ + 2Ag
14. Cl⁻ + Ag⁺ = AgCl↓
15. CO₃²⁻ + 2Ag⁺ = Ag₂CO₃↓
16. Ag₂CO₃ + 2H⁺ = 2Ag⁺ + CO₂↑ + H₂O

---

### 三、氧化还原反应（基本置换、燃烧、工业反应）

17. 2CuO + C =高温= 2Cu + CO₂↑
18. Fe₂O₃ + 3CO =高温= 2Fe + 3CO₂
19. Fe + CuSO₄ = FeSO₄ + Cu
20. H₂O + C =高温= H₂ + CO
21. 2Al + Fe₂O₃ =高温= 2Fe + Al₂O₃
22. WO₃ + 3H₂ =高温= W + 3H₂O
23. Zn + 2HCl = ZnCl₂ + H₂↑
24. MnO₂ + 4HCl(浓) =Δ= MnCl₂ + Cl₂↑ + 2H₂O
25. CuO + 2HCl = CuCl₂ + H₂O
26. 2H₂ + O₂ =点燃= 2H₂O
27. 4P + 5O₂ =点燃= 2P₂O₅
28. Fe + H₂SO₄ = FeSO₄ + H₂↑
29. 2HgO =Δ= 2Hg + O₂↑
30. NaH + H₂O = NaOH + H₂↑
31. 2H₂O₂ =MnO₂催化= 2H₂O + O₂↑
32. H₂O₂ + H₂S = 2H₂O + S↓
33. H₂O₂ + Cl₂ = 2HCl + O₂
34. 3ClO⁻ + 2Fe³⁺ + 10OH⁻ = 2FeO₄²⁻ + 3Cl⁻ + 5H₂O
35. S + 2KNO₃ + 3C = K₂S + N₂↑ + 3CO₂↑
36. 6Fe²⁺ + Cr₂O₇²⁻ + 14H⁺ = 6Fe³⁺ + 2Cr³⁺ + 7H₂O
37. 火法炼锌（菱锌矿，分两步）：
    - ZnCO₃ =高温= ZnO + CO₂↑
    - ZnO + C =高温= Zn + CO↑

### 四、钠及其化合物

38. 4Na + O₂ = 2Na₂O（常温）
39. 2Na + O₂ =Δ= Na₂O₂
40. 2Na + 2H₂O = 2NaOH + H₂↑
41. 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑
42. 2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂
43. 2NaHCO₃ =Δ= Na₂CO₃ + H₂O + CO₂↑
44. 2Na + Cl₂ =Δ= 2NaCl

---

### 五、氯及其化合物

45. 2Fe + 3Cl₂ =Δ= 2FeCl₃
46. Cu + Cl₂ =Δ= CuCl₂
47. H₂ + Cl₂ =点燃或光照= 2HCl
48. Cl₂ + H₂O ⇌ HCl + HClO（可逆）
49. 2HClO =光照= 2HCl + O₂↑
50. Cl₂ + 2NaOH = NaCl + NaClO + H₂O
51. 2Cl₂ + 2Ca(OH)₂ = Ca(ClO)₂ + CaCl₂ + 2H₂O（冷石灰乳）
52. Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO

### 六、铁及其化合物

### 七、铝及其化合物
